# Skins, Sleeves and Sheaths: ICRA 2027 Workshop

Website for the ICRA 2027 workshop *Skins, Sleeves and Sheaths: Scalable Robotic Materials that Sense, Actuate and Conform*.

Live at: https://skins-sleeves-sheaths-workshop.github.io

Plain HTML + CSS, no build step. Edit the files and push; GitHub Pages serves them directly.

- `index.html` – home page (about, topics, speakers, schedule, organizers, sponsors)
- `call-for-contributions/index.html` – call for papers
- `assets/css/style.css` – all styling; colours are set at the top
- `assets/img/` – speaker, organizer and sponsor images

Copy-paste templates for speaker and organizer cards are in HTML comments inside `index.html`.
Look for `TODO` to find the placeholders that still need filling in.

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000
